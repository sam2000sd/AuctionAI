AuctionAI quick start

1. Run START_VISIBLE.bat.
2. First run on a computer may install dependencies once.
3. The Python environment is stored outside this folder at %LOCALAPPDATA%\AuctionAI, so deleting/replacing this app folder is fast.
4. If setup breaks, run RESET_ENVIRONMENT.bat.
5. If you have an old extracted app folder with .venv inside it, run REMOVE_OLD_LOCAL_ENV.bat before deleting the folder to clean it up.
